## ステップ19 で理解すること — プロンプトでは止まらず、権限も経路ごとに閉じる

プロンプトで「.env を読まないこと」と書いても、モデルは bash の cat で読んだ。止めたのは権限ルールだった。
権限ルールは allow > deny > ask の順で効くので、allow に bash を入れておけば deny の個別指定より強い。
MCP のツールにも同じルールが効く。workspace の外へは MCP からも出られるので、閉じ込めは権限ルールだけが頼り。
