# 実測の残し方

このリポジトリの決まりは「**実測を README に残すまでがステップ**」。
動いたことの確認ではなく、**前後の差**を出す。

## 何を測るか

| 入れたもの | 測るもの |
|---|---|
| ツールを足した | ツール呼び出し回数 / 入力トークン / 承認を求めた回数 |
| コンテキストを削る仕組み | 累計入力トークン、削った件数、削るのに使ったトークン |
| 承認・権限 | 聞かれた回数、通った回数、止まった回数 |
| 非同期・並列 | 時刻つきのタイムライン（親が次に進んだ時刻） |

## 取り方

1. **同じ入力**で前後を走らせる。プロンプトを変えたら比較にならない
2. 出力はそのまま貼る。整形しても数字は変えない
3. 失敗した試行も残す。「最初はこうして駄目だった」が一番の教材になる
4. 時刻が要るときは `perl -ne 'BEGIN{$t0=time()} printf("%5.1fs %s", time()-$t0, $_)'` に流す
5. ClickHouse が上がっているなら `gate` / `usage` イベントを数える

## 書き方

- 「### 実測: 〜」の見出しで置く
- 表は2列（前 / 後）にして、**太字で効いた数字**を示す
- 効かなかったものは「負けた」と書く。TRIM=graph の節がその例
