# コミットメッセージの作法

このリポジトリのコミットは**教材**として読まれる。何をしたかではなく、
**なぜそうしたか・何を実測したか・あえてやらなかったこと**を残す。

## 形

```
日本語の1行サマリ（体言止めにしない。何が変わったかを動詞で言う）

なぜそれが要るのか。何が壊れていたのか。素朴版の何が駄目だったのか。

実測を、コピーした出力か表で置く。数字は丸めない。

あえてやらなかったことと、その理由。
```

## 守ること

- サマリは50字前後。「〜を追加」で終わらせない。**何が変わったか**を言う
- 本文は日本語。折り返しは90字くらい
- 表は ASCII で揃える（README の表をそのまま貼らない）
- 「リファクタ」「改善」と書かない。何がどう変わったかを具体的に書く
- 実測が無いコミットは、実測を取ってからにする

## やらないこと

- 複数の関心事を1つのコミットに混ぜない。分けられるなら分けて提案する
- 言われる前に commit しない。実装 → 提示 → レビュー → 指示、の順
